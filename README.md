## Overview

This repository showcases a series of data engineering workflows and projects using popular tools and platforms like **Apache Airflow**, **Azure Data Factory**, **Databricks**, **Luigi**, and **PySpark**. Each project focuses on automating data pipelines, data transformation, machine learning workflows, and bioinformatics analysis.

## Projects

### airflow_rnaseq

This section previously contained an Airflow submodule for RNA sequencing pipelines. It has now been removed from the repository. You can explore other submodules and workflows below.

### azure_data_factory

- **Description**: This project demonstrates a data pipeline using Azure Data Factory.
- **Content**: The Azure Data Factory repository has been merged into a subfolder for easier access and organization. This folder includes data processing workflows for cloud-based ETL pipelines.
- **Path**: `azure_data_factory/`

### databricks_project

- **Description**: Contains Databricks notebooks and projects related to machine learning model training.
- **Changes**: The file `ml_model_training_notebook.py` has been deleted as part of the cleanup.
- **Path**: `databricks_project/`

### luigi_data_pipeline

- **Description**: A Luigi-based data pipeline project designed for managing complex ETL workflows.
- **Details**: The pipeline setup is provided to demonstrate task automation and dependency management.
- **Path**: `luigi_data_pipeline/`

### variant-filtering-pyspark

- **Description**: A PySpark-based bioinformatics pipeline for filtering genetic variants based on various criteria.
- **Details**: This project has been added as either a submodule or a subdirectory for handling variant filtering in genomic data using PySpark.
- **Path**: `variant-filtering-pyspark/`

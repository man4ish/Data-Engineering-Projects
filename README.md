# Data Engineering Projects

Welcome to my **Data Engineering Projects** repository! This collection includes hands-on examples of real-world data engineering workflows, automation, and infrastructure setups. These projects span across multiple technologies like **Airflow**, **Azure Data Factory**, **Databricks**, **Pyspark**, and more.

## 📁 Repository Structure

Each project is organized in its own folder with:

- **README.md** – Project overview, key insights, and setup instructions
- **Python Scripts / Notebooks** – Implementation of data engineering pipelines
- **Data** – Links or sample datasets used
- **Visuals / Output** – Visualizations, workflow diagrams, and logs (if any)

### 🌟 Featured Projects

1. **[Airflow RNA-Seq Pipeline](airflow_rnaseq/README.md)**  
   - **Description**: Built an Airflow pipeline to process and analyze RNA-Seq data, integrating with various external services.
   - **Tech Stack**: Apache Airflow, Python, Bash
   - **Focus**: Workflow orchestration, pipeline automation, scalability

2. **[Azure Data Factory](azure_data_factory/README.md)**  
   - **Description**: Set up an end-to-end ETL pipeline using Azure Data Factory for data movement and transformation from on-premises to cloud environments.
   - **Tech Stack**: Azure Data Factory, SQL, Azure Storage
   - **Focus**: Cloud data integration, ETL automation

3. **[Databricks ML Model Training](databricks_project/README.md)**  
   - **Description**: Created a Databricks notebook to train machine learning models on large-scale data in a collaborative environment.
   - **Tech Stack**: Databricks, PySpark, Python
   - **Focus**: Distributed computing, machine learning model training

4. **[Luigi Data Pipeline](luigi_data_pipeline/README.md)**  
   - **Description**: Developed a data pipeline using Luigi to automate data extraction, transformation, and loading (ETL).
   - **Tech Stack**: Luigi, Python
   - **Focus**: Workflow orchestration, task management, scheduling

5. **[Variant Filtering with PySpark](variant-filtering-pyspark/README.md)**  
   - **Description**: Implemented a variant filtering pipeline using PySpark to process large genomics datasets efficiently.
   - **Tech Stack**: PySpark, Python
   - **Focus**: Big data processing, data transformation, performance optimization
